# ResumeCraft – Premium Resume Builder

> Build Beautiful Professional Resumes in Minutes

ResumeCraft is a premium, client-side web application that helps students, freshers, and professionals create beautifully designed, professional resumes without needing Microsoft Word, complicated software, or even an account. Everything works directly inside the browser, offering a fast, smooth, and highly responsive user experience.

---

## 🚀 Features

- **Live Preview:** See your resume update instantly as you type. No refresh required.
- **PDF Download:** Export your polished resume directly to a high-quality PDF.
- **Multiple Templates:** Choose from Modern, Professional, Minimal, and Creative layouts instantly.
- **Dark Mode / Light Mode:** Beautiful, smooth theme switching with memory.
- **100% Responsive:** Works flawlessly on desktop, tablet, and mobile devices.
- **Auto Save:** Never lose your work. Data is automatically saved to your browser's Local Storage.
- **Profile Photo Upload:** Easily crop and add your professional avatar directly in the browser.
- **Dynamic Sections:** Add unlimited education, projects, experience, certificates, achievements, and languages.
- **Custom Sections:** Build your own personalized resume sections (e.g., Volunteer Work, Open Source).
- **Smart Validation:** Real-time form validation to guide users toward a complete resume.
- **Print Resume:** Dedicated print stylesheets to easily print the exact resume format.

---

## 💻 Technologies Used

Built entirely with core frontend web technologies for maximum performance and zero backend dependency:

- **HTML5:** Semantic architecture and fully accessible structure.
- **CSS3:** Custom design system, glassmorphism, flexbox/grid layouts, and native CSS variables.
- **Vanilla JavaScript (ES6+):** Complete logic, DOM manipulation, state management, and event handling. No frameworks.
- **Font Awesome 6:** Premium icons.
- **Google Fonts:** Modern typography (Poppins, Inter, Roboto, Lato, Open Sans).
- **html2pdf.js:** High-quality client-side PDF generation.

## 🛠️ Installation & Usage

Because ResumeCraft is a purely client-side application, getting started is incredibly simple:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Gunjan9711/ResumeCraft.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd ResumeCraft
   ```
3. **Run locally:**
   Simply open `index.html` in your favorite modern web browser (Chrome, Firefox, Safari, Edge).
   *Optional: If you use VS Code, you can run it using the "Live Server" extension.*

### Deploy on Vercel
ResumeCraft can be instantly deployed to Vercel, Netlify, or GitHub Pages. No build step or server configuration is required. Just connect your repository and deploy the root directory.
